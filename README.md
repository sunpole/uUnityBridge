# uUnityBridge 0.4.0 — Windows desktop agent + EXE updater (P0004 preview)

**Разработка в PR.** Пока нет подтверждённой проверки установки и отката на Windows пользователя. Рабочая версия 0.3.0 остаётся доступной.

## Работа
- Автоматический опрос GitHub Issues раз в 60 секунд для безопасных PATCH/ANS.
- Одна большая кнопка «ОТЧЁТ» копирует только новые опубликованные ANS.
- Проверка опубликованных стабильных GitHub Releases при запуске и далее раз в 30 минут.
- При обнаружении версии выше установленной: получение `uUnityBridge.exe` и `uUnityBridge.exe.sha256`, проверка SHA256 и передача замены отдельному `uUnityBridge.Updater.exe`.
- Companion helper ждёт завершения старого процесса, сохраняет резервную EXE, подменяет файл и запускает новую программу. Если окно не подтвердило запуск, helper пытается восстановить прежний EXE и запустить его.
- Небольшая ссылка «↶ Откат версии» появляется лишь при наличии резервной копии для данной папки установки.
- Исправлена подсказка «СКОПИРОВАТЬ» → «ОТЧЁТ».
- Данные и отчёты в `%LOCALAPPDATA%\uUnityBridge` не удаляются при замене EXE.

## Первоначальная установка

0.3.0 **ещё не умеет устанавливать обновления EXE**. Первый переход на 0.4.0 требует один раз вручную распаковать **оба** файла `uUnityBridge.exe` + `uUnityBridge.Updater.exe` из CI-артефакта в отдельный каталог и запустить новый EXE. Нельзя пытаться заменять запущенную 0.3.0. После QA можно опубликовать стабильный Release.

## Ограничения безопасности

Никакие PowerShell-команды или EXE из GitHub Issues не исполняются. Обновления бинарника доступны только из стабильных Releases того же репозитория. SHA256 подтверждает целостность относительно файла контрольной суммы **из того же Release**, но не заменяет цифровую подпись издателя. Текущая версия не подписана сертификатом Authenticode; защита выпуска также зависит от доступа к GitHub-репозиторию и CI. Для production рекомендуется подписывать бинарники и включить immutable Releases.

Программа не меняет политику Windows и не требует администратора при доступе на запись в текущую папку.
