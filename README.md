# uUnityBridge 0.3.0 — Windows desktop PATCH / ANS agent

**P0003 в разработке:** один большой «ОТЧЁТ», автоматическая проверка GitHub раз в 60 секунд, применение только разрешённых PATCH, публикация ANS и закрытие законченных заданий. [Архитектура P0003](docs/P0003_AUTOPILOT.md).

Программа должна работать в обычном окне без дополнительных подтверждений для уже разрешённых видов операций. Кнопка «ОТЧЁТ» доступна только при новых опубликованных результатах и копирует **разницу после предыдущего копирования**, а не старый P0001/P0002. Предыдущие ответы при первом переходе с 0.2.1 считаются уже скопированными.

## Возможности и ограничения

- GitHub: `sunpole/uUnityBridge`; вход `gh` от `sunpole`.
- Гарантированно разрешённые действия: `report-only` и `sync-main` с проверкой SHA, checkpoint и fast-forward.
- При потере сети — повтор с увеличением паузы, без бесконечных запросов.
- При ошибке PATCH — ограниченные повторы и BLOCKED.
- Локальный журнал защищает от повторного применения и повторного копирования.
- Одна копия агента за раз (для новых версий).
- **НЕТ** выполнения произвольных команд, инсталляций Unity, фоновой службы Windows или автоматической замены запущенного EXE.
- **НЕТ** прямого inbound API/MCP и подключения DeepSeek. Эксперимент DeepSeek — разовые $5, [правила здесь](docs/DEEPSEEK_TRIAL.md).
- Автопроверка действует только пока приложение запущено.
- Публичные отчёты содержат лишь ограниченный статус, не содержат API-токенов и локальных ошибок.

## Сборка

Windows 10/11, .NET SDK 8, Git и GitHub CLI. Из папки проекта:

```powershell
dotnet publish ./src/uUnityBridge.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ./dist/win-x64
```

GitHub Actions проверяет Windows сборку и тесты очереди. Готовые CI-артефакты пока **не являются** подписанным релизом или автообновлением.
