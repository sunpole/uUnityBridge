# P0008 — локальный агент разработки: итерация A

## Что реализовано

Отдельный проект agent/uUnityBridge.Agent.csproj, C#/.NET 8 Windows.
Он предоставляет структурированный JSON API по Windows Named Pipe, доступный только текущему пользователю.
Без администратора, без локального/публичного HTTP, без ngrok, без универсального PowerShell.

Доступные методы: health, capabilities, github_status, repo_status, workflow_preview.
Последний метод последовательно проверяет состояние агента, GitHub CLI и фиксированного репозитория sunpole/uUnityBridge.
Инструменты GitHub используют только заранее зафиксированные параметры чтения и не печатают stdout/stderr потенциальных секретов.
Запросы ограничены по длине и времени. Отсутствует исполнение команд из GitHub Issues.

## Проверка после CI

CI публикует только артефакт uUnityBridge.Agent.exe для тестирования.
Существующая установка uUnityBridge_App версии 0.4.2 не затрагивается.

В первом окне PowerShell обычного пользователя: uUnityBridge.Agent.exe --serve
Во втором окне: uUnityBridge.Agent.exe --request health
Во втором окне: uUnityBridge.Agent.exe --request workflow_preview
Остановка агента: Ctrl+C.

Не запускать от администратора. Никаких API-ключей или Python для этого этапа.

## Что ещё НЕ реализовано

Эта версия НЕ является автономной ИИ-системой: нет LLM-подключения, управления исходниками,
редактирования проектов, скриншотов, GUI-операций или прямого ChatGPT MCP.
Текущая цель — проверяемый безопасный локальный транспорт.
